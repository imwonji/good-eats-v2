# 2단계 · 앱 설명 요약 — Good Eats v2

> **친구들의 취향을 모아 모두가 만족할 식당을 골라준다.**
> 카테고리: 음식 및 음료 · 참조 앱: Beli

## 목표
친구들과 "오늘 어디서 먹지?"를 정하는 시간을 **단톡방 30분 → 앱 안 3분**으로 줄이고, 모두가 납득하는 한 곳을 고른다.

## 대상 사용자 (퍼소나)
| 항목 | 내용 |
|---|---|
| 이름 · 나이 | 이서윤 (가상 인물) · 21세 |
| 소속 | 대학교 2학년, 동아리 총무 — 모임 장소를 자주 정하는 사람 |
| 사용 기기 | 스마트폰 (단톡방 · 지도 앱 · Beli) |
| 행동 | 일주일에 2–3번 친구·동기와 식사. Beli에 개인 맛집 기록 |
| 목표 | 모두가 불만 없이 갈 수 있는 식당을 빨리 정하고 싶다 |
| 불편 | 단톡방에서 의견이 엇갈리고 답장이 늦다. 누가 뭘 못 먹는지, 예산이 얼마인지 매번 다시 물어야 한다. 결국 서윤이 혼자 정하고 눈치를 본다 |
| 한마디 | "다들 '아무거나'라고 하면서, 정하면 꼭 한 명은 싫대요." |

## 해결할 문제
1. **결정이 앱 밖에서 일어난다** — Beli는 개인 순위 앱이라 그룹 결정 기능이 없다. 결국 "그냥 친구들에게 직접 물어보면 되잖아요"(R6, ★1)
2. **조건이 흩어져 있다** — 예산·지역·못 먹는 음식이 단톡방 여기저기에 묻혀, 정한 뒤에야 문제가 드러난다 (P05 위반)
3. **비교가 기억에 의존한다** — 예전 식당을 떠올려 비교해야 한다 (R4, ★3 · P06 위반)

## AI 기능
멤버들의 배틀 선택, 예산, 위치, 못 먹는 음식을 분석해 모두에게 맞는 식당 1곳을 추천하고 **추천 이유**를 설명한다.
(이번 구현에서는 json-server의 미리 정한 결과를 보여줌 — 실제 추천 알고리즘 없음)
