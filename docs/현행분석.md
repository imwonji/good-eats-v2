## 6. 결론 → Good Eats v2의 기회
- Beli는 **혼자** 순위를 매기는 앱이다. 친구들과 함께 쓰는 사용자는 많지만(R1, R3), **"오늘 다 같이 어디 갈지"를 정하는 기능은 없다**. 그래서 결국 "그냥 친구들에게 직접 물어보면 되잖아요"(R6) — 결정은 앱 밖 단톡방에서 일어난다.
- Good Eats v2는 Beli의 장점(비교 방식 P02·P05, 친구 신뢰 R1)을 유지하고, 문제점을 이렇게 고친다:

| Beli 문제 | Good Eats 화면 |
|---|---|
| 기억해 내서 비교 (P06, R4) | S3 취향 배틀 — 선택지를 이모지·종류·가격과 함께 **화면에 보여주고**, 3라운드만 |
| 빈 화면·무반응 (P01·P09, R6) | 모든 화면 로딩·오류(다시 시도)·빈 상태 안내 |
| 결정 정보가 가려짐 (P01, R5) | S2② 예산·지역·못 먹는 음식을 결정 전에 표시, S4② 추천 이유 · S4③ 멤버별 만족도 공개 |
| 그룹 결정 기능 없음 (R6) | S2 그룹 → S3 배틀 → S4 AI 추천 → 그룹에 보내기 |
