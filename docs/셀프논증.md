# 셀프 논증 기록

> 쟁점마다: 내 주장 → 반론(AI 반론 + 스스로 찾은 반론) → 재반론·수정 → 결론 → 근거(P번호·리뷰) → 전·후 화면
> 증거: `docs/prompt-log.md` #3 · #4, 원칙 카드(발표자료 B2), 코드 주석 `// C-6 P01` · `// C-7 P05` · `// D-6 P03`

## 쟁점 1. 취향 수집 방식 — A/B 2지선다 3라운드
- **내 주장**: 화면에 보이는 두 선택지 중 하나만 고르면 예전 식당을 기억해 낼 필요가 없고 3라운드면 끝난다. (P06 · #4 ★3 "비교 대상이 되는 식당들을 기억하기가 정말 어렵거든요")
- **AI 반론** (prompt-log #3)
  - P07: 양자택일은 선호의 강도를 담지 못한다 ("조금 좋음"과 "매운 건 절대 싫음"이 같은 한 번의 탭).
  - P05: 배틀에 그룹이 못 먹는 음식(예: 해산물)이 나올 수 있다.
  - P01: 그룹 안에서 누가 끝냈고 누구를 기다리는지 안 보여 결정이 다시 멈춘다.
- **스스로 찾은 반론**: #4 리뷰어는 비교 대신 10점 만점 점수를 원했다.
- **재반론 / 수정**: 10점 점수는 다시 예전 식당을 기억해 내야 하고 사람마다 기준이 달라 그룹 취향으로 합치기 어렵다 → A/B 방식은 유지. AI 반론 중 P05 · P01은 받아들여, 그룹이 못 먹는 음식은 배틀에서 뺐다고 알리고(C-7), 투표 현황 "3 of 4 members done"을 보인다(C-6).
- **결론**: 수정
- **근거**: P06 · P05 · P01 · #4 ★3
- **전 → 후 화면**: 화면 C (C-1~C-5) → 화면 C + C-6 투표 현황 · C-7 제외 음식 안내

## 쟁점 2. 추천 결과 개수 — AI 추천은 한 곳만
- **내 주장**: 여러 곳을 목록으로 주면 단톡방 토론이 다시 시작된다. 답 하나가 결정을 끝낸다. (P08)
- **AI 반론** (prompt-log #4)
  - P03: 답이 하나면 강요처럼 느껴지고, 거절하면 "다시 고르기"로 배틀을 처음부터 해야 한다.
  - 그 한 곳이 꽉 찼거나 문을 닫았으면 대안이 없어 다시 단톡방으로 돌아간다.
  - P10: 대안이 없으면 AI의 선택이 임의로 보인다.
- **스스로 찾은 반론**: 목록이 길어지면 결국 #6 ★1 "그냥 친구들에게 직접 물어보면"으로 돌아간다 — 내 주장을 지지하는 반론이기도 하다.
- **재반론 / 수정**: 답은 하나로 크게 유지(D-1, P08). 추천 이유(D-2)와 멤버별 만족도(D-3)로 임의성 반론에 답한다. 대신 그 아래에 작은 백업 후보 2곳을 둔다(D-6, P03) — 꽉 찼을 때 처음부터 다시 하지 않아도 된다.
- **결론**: 수정
- **근거**: P08 · P03 · #6 ★1
- **전 → 후 화면**: 화면 D (D-1~D-5) → 화면 D + D-6 백업 후보
