# 디자인 가이드 — Good Eats v2

번호(A-1 …)는 코드 주석 `// A-1 P02`와, 비즈니스 명칭은 발표자료 B5-4와 같다.

## 공통 규칙
- Material 3, seed `#E8572A` — 모든 화면 동일 (P04)
- 한 화면에 주요 행동 1개, 카드 단위로 정보 묶음 (P08)
- 데이터 화면은 로딩 → (오류 | 빈 상태 | 내용) — `lib/widgets/states.dart` (P01 · P09 · P10)
- 적응형: 폭 700px 이상 그리드 · 두 단, 미만 한 단
- 정보 전달 기준: 결정에 필요한 조건(예산 · 지역 · 못 먹는 음식)을 결정 버튼보다 먼저
